Endpoint

Retrieve all available tariffs. 

GET /api/tariffs

Python Example

Include your API key in the X-API-Key request header. 

import requests

response = requests.get(
    "http://127.0.0.1:5000/api/tariffs",
    headers={
        "X-API-Key": "YOUR_API_KEY"
    }
)

data = response.json()

for tariff in data:
    print(tariff["name"])

JavaScript Example

Example request using the Fetch API. 

fetch("/api/tariffs", {
    headers: {
        "X-API-Key": "YOUR_API_KEY"
    }
})
.then(response => response.json())
.then(data => {
    console.log(data);
});

Response Fields

Field Description
id Unique tariff identifier.
provider Name of the mobile provider.
name Name of the tariff.
price Monthly tariff price in EUR.
gb Included mobile data.
minutes Included call minutes.

Authentication

This endpoint requires an API key. After registering and logging in, your API key is available on your profile page. Send it using the X-API-Key request header. 

X-API-Key: YOUR_API_KEY

Rate Limits

No request limits are currently enforced. Rate limiting may be introduced in future versions of the API to improve reliability and prevent abuse.
